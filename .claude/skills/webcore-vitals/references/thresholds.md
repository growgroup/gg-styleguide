# CWV 基準値とスロットリング設定

## 基準値
| 指標 | Good | Needs Improvement | Poor |
|---|---|---|---|
| LCP | ≤ 2.5s | ≤ 4.0s | > 4.0s |
| CLS | ≤ 0.1 | ≤ 0.25 | > 0.25 |
| INP | ≤ 200ms | ≤ 500ms | > 500ms |
| FCP（参考） | ≤ 1.8s | ≤ 3.0s | > 3.0s |
| TTFB（参考） | ≤ 0.8s | ≤ 1.8s | > 1.8s |

## スロットリング（必須・モバイル相当 / Lighthouse デフォルト準拠）
- ネットワーク: Slow 4G
- CPU: 4x スローダウン

localhost はスロットリング無しだと速すぎて基準評価が無意味になる。計測前に必ず適用すること。
